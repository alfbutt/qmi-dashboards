⚙️ Connect Google Sheet

○  Not connected yet
Simpler than Apps Script — no coding or deployment needed.
  1. Go to console.cloud.google.com → sign in with your Google account
  2. Create a project (or pick an existing one) → click Enable APIs → search Google Sheets API → Enable
  3. Click Credentials → Create Credentials → API Key
  4. Copy the key and paste it above → click Save & Sync
or use Apps Script
  1. Open your Google Sheet → Extensions → Apps Script
  2. Delete everything, click below to copy the script, paste it in
  3. Deploy → New deployment → Web app → Execute as Me → Anyone → Deploy
  4. Copy the URL → paste above → Save
🔔 Slack Notifications
Create a Slack App → add channels:history permission → install to workspace → copy Bot Token.
Right-click the channel in Slack → Copy link → the ID is the last part (e.g. C06ABC123).
